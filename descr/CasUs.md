 Cliente consulta productos por necesidad

Actor: cliente o usuario visitante.

Flujo feliz:

El usuario entra al chat.
Escribe una necesidad comercial.
Ejemplo: “Tengo un kiosco y quiero productos económicos para revender”.
El asistente interpreta la consulta.
Busca productos relacionados en el catálogo.
Muestra recomendaciones con precio, stock y justificación.
El usuario recibe una respuesta útil sin navegar todo el catálogo.

Resultado esperado:

El usuario encuentra productos adecuados rápidamente.

2. Cliente consulta precio de un producto

Actor: cliente o usuario visitante.

Flujo feliz:

El usuario pregunta por un producto específico.
Ejemplo: “¿Cuánto sale la tutuca dulce x 1kg?”.
El asistente busca el producto en la base de datos.
Devuelve precio unitario, precio mayorista y stock.
También puede indicar si aplica alguna condición comercial.

Resultado esperado:

El usuario obtiene precio y disponibilidad de forma inmediata.

3. Cliente pide recomendación para comprar

Actor: cliente potencial.

Flujo feliz:

El usuario describe su tipo de negocio.
Ejemplo: “Tengo un almacén chico y quiero comprar productos con buena salida”.
El asistente identifica el perfil del cliente.
Compara productos disponibles.
Recomienda 2 o 3 opciones convenientes.
Explica por qué esos productos pueden servirle.

Resultado esperado:

El usuario recibe una recomendación comercial personalizada.

4. Cliente consulta condiciones comerciales

Actor: cliente potencial.

Flujo feliz:

El usuario pregunta por condiciones de compra.
Ejemplo: “¿Cuál es la compra mínima para mayorista?”.
El asistente consulta las condiciones comerciales.
Responde compra mínima, descuentos, medios de pago y plazo de entrega.
El usuario entiende si puede comprar como minorista, mayorista o distribuidor.

Resultado esperado:

El usuario recibe reglas comerciales claras.

5. Cliente deja sus datos de contacto

Actor: cliente interesado.

Flujo feliz:

El asistente detecta interés comercial.
Pregunta si desea dejar sus datos.
El usuario informa nombre, teléfono, empresa y necesidad.
El sistema crea un lead.
El asistente genera un resumen de la conversación.
El lead queda guardado en el sistema.

Resultado esperado:

Se registra una oportunidad comercial sin cargar datos manualmente.

6. Usuario interno revisa leads registrados

Actor: vendedor o administrador.

Flujo feliz:

El usuario entra a la vista “Leads registrados”.
Ve la lista de clientes interesados.
Filtra por estado: nuevo, interesado o contactado.
Abre un lead.
Lee el resumen generado por IA.
Cambia el estado del lead si corresponde.

Resultado esperado:

El vendedor puede priorizar contactos comerciales.

7. Usuario guarda leads en Google Sheets

Actor: vendedor o administrador.

Flujo feliz:

El usuario revisa un lead registrado.
Presiona “Guardar en Google Sheets”.
El sistema envía nombre, contacto, empresa, interés y resumen.
La planilla queda actualizada.

Resultado esperado:

El negocio conserva los leads en una fuente externa simple.
